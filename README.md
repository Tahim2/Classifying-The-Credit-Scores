# Classifying Credit Scores

This project builds and evaluates multiple machine learning models to classify customer credit scores as **Bad**, **Standard**, or **Good**.

## 🚀 Project Overview

- Predict credit score categories using customer financial and behavioral data.
- Preprocess data: handle missing values, encode features, cap outliers.
- Train and evaluate models:
  - Logistic Regression
  - Random Forest
  - XGBoost
  - Gradient Boosting
  - AdaBoost
  - LightGBM
  - CatBoost
- Visualize performance with:
  - Confusion matrices
  - ROC curves and AUC scores
- Explain model predictions using SHAP.

## 📦 Tech Stack

- Python
- scikit-learn
- XGBoost
- LightGBM
- CatBoost
- SHAP
- seaborn / matplotlib
